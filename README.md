## 🌤 Telegram-бот погоды

Бот показывает погоду в городах России. Без регистрации и API-ключей.

**Возможности:**
-  Поиск города
- ➕ Добавление городов в список
- 🌤 Погода для всех выбранных городов
- ❌ Удаление городов
- 💾 Список сохраняется автоматически

**Запуск:**
1. Токен от @BotFather → вставь в `bot.py`
2. `pip install pyTelegramBotAPI requests`
3. `python bot.py`

API: Open-Meteo (бесплатно, без регистрации).
