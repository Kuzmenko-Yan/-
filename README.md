## 🌤 Telegram-бот погоды

Бот показывает погоду в городах России. Без регистрации и API-ключей.

**Возможности:**
- 🔍 Поиск города по названию
- ➕ Добавление нескольких городов в список
- 🌤 Просмотр погоды для всех выбранных городов
-  Удаление городов из списка
- 💾 Список городов сохраняется автоматически

**Запуск:**
1. Получи токен у @BotFather в Telegram
2. Вставь токен в `bot.py` вместо `YOUR_TELEGRAM_BOT_TOKEN`
3. Установи библиотеки: `pip install pyTelegramBotAPI requests`
4. Запусти: `python bot.py`

Используется бесплатный API Open-Meteo — регистрация не нужна.
